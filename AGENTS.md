# Documentation Retrieval

Documentation lives in docs/.

Before working on an unfamiliar subsystem:
1. Read docs/README.md to identify relevant documents.
2. Read only documentation relevant to the task.
3. Follow links when additional context is necessary.
4. Inspect the actual source code to verify documentation.

Do not read the entire docs directory by default.

When implementing significant changes:
- Update affected documentation.
- Update docs/README.md when adding documents.
- Preserve cross-references between related systems.
