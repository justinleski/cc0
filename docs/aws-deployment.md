# AWS deployment

Status: Not implemented. No AWS infrastructure is provisioned by this repository.

The [MVP spec](mvp-spec.md#first-aws-deployment) describes the intended pilot and
[low-cost topology](mvp-spec.md#low-cost-aws-topology-after-local-acceptance).
Milestone M5 runs only when requested, after local acceptance. Local development
needs no AWS account; see [local development](local-development.md).
