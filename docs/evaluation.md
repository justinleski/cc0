# Evaluation

Status: Not implemented.

Search and board ranking benchmarks belong to milestone M4. The
[MVP spec](mvp-spec.md#search-evaluation) defines that evaluation. M2 search is
implemented and covered by filter and ordering tests; see
[search](systems/search.md) and [lint and tests](lint-test.md). A cache for
query embeddings is deferred until repeated queries show up in latency.
